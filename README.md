# Grupo SAFE 2.0 — estrutura inicial

Página inicial responsiva, sem framework e pronta para GitHub Pages.

## Arquivos
- `index.html` — estrutura e conteúdo.
- `style.css` — identidade visual, responsividade e animações.
- `script.js` — menu mobile, animações de entrada, progresso de rolagem e formulário para WhatsApp.
- `assets/` — imagens da marca.

## Imagens a adicionar
Coloque na pasta `assets` os arquivos:
- `logo-grupo-safe.png` — logotipo oficial, de preferência PNG transparente.
- `mascotes-equipe.png` — os dois mascotes juntos para o destaque inicial.
- `mascote-seguranca.png` — mascote individual para a seção Sobre.

Se não adicionar as imagens ainda, aparecem espaços reservados.

## Configuração obrigatória
No `script.js`, substitua `5500000000000` pelo WhatsApp oficial do Grupo SAFE, com DDI e DDD, apenas números.

## Publicação
Envie os arquivos para a raiz do repositório. No GitHub, acesse **Settings → Pages → Deploy from a branch**, escolha sua branch principal e a pasta `/ (root)`, e salve.

Revise os textos e a lista de serviços para confirmar que representam o escopo efetivamente oferecido pela empresa antes de publicar.
